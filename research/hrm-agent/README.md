# HRM Agent Research

This folder contains experimental work on a simplified Hierarchical Reasoning Model (HRM) applied to a simplified RL task inspired by RTS gameplay.

- Paper reference: [HRM (Hierarchical Reasoning Model)](https://arxiv.org/pdf/2506.21734)

Scope:

- Reproduce a strongly simplified HRM in a controlled RL setting (no online gameplay).
- Use a toy RTS-like environment to evaluate hierarchical planning/execution.
